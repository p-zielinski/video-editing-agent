# Legacy prompts (v1)

These prompts are **deprecated**. The current pipeline loads agent prompts from **`prompts/v2/`** by default.

Do not edit v1 for new features — port changes to the matching file under `prompts/v2/` (director, critic, fixer, summarizer, super-director, segment-director, …).

To force v1 in ad-hoc experiments only: `PROMPT_VERSION=v1` (not supported for production runs).
